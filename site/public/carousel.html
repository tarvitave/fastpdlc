FastPDLC09
Proof, not a promise

It found a bug in itself.

The blog on fastpdlc.com is stored as product-as-code — ids matching filenames, categories from an allowed set, every cross-link resolving. So it goes through the same gate as everything else.

TypeError: Object of type date is not JSON serializable

An unquoted date in frontmatter became a Python object the bundle could not serialise. Any project with a date field would have hit it. Fixed in 0.2.0, with a regression test.
