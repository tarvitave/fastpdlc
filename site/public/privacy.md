# What this site collects.

Short version: an email address if you type one
 into the form, and aggregate page counts. No cookies, no third-party trackers, no
 advertising networks.

## If you subscribe

The form stores the email address you enter, the word `landing` to record
 where it came from, the time, and a salted one-way hash of your IP address used only for
 rate limiting. The hash cannot be reversed to an IP.

The address is used to send release notes and news about new diagnostic codes, no more
 than monthly. It is not sold, rented, or shared. Every email carries an unsubscribe link,
 and you can ask for deletion at any time at the address below.

## Analytics

Page views are counted with a self-hosted, cookieless analytics instance running on the
 same server as this site. It records the page URL, referrer, rough screen size, and a
 country derived from the IP address, which is not stored. Nothing follows you to other
 sites, and no data leaves this server.

## Third parties

There are none on this site. Fonts, stylesheets and scripts are all served from
 `fastpdlc.com`, so your browser makes no request to any other host while
 reading it — no font CDN, no analytics vendor, no tag manager, no embedded
 widgets. Nothing about your visit reaches anyone but us.

## Hosting

The site runs on a server in the European Union. Standard web server logs (IP address,
 request line, user agent) are kept briefly for operational and security purposes and then
 rotated away.

## Your rights and contact

You can ask what is stored about you, ask for a copy, or ask for it to be deleted.
 Open an issue on [GitHub](https://github.com/tarvitave/fastpdlc/issues), or
 write to the address listed in the repository.
